# Pratham Gupta — Portfolio

A responsive, static portfolio for Pratham Gupta, built from verified public GitHub and LinkedIn details and user-provided profile materials.

## Run locally

Serve this directory with any static file server, then open the local address in a browser. There is no package installation or build step.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages on every push to `main` and on manual runs. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

## Notes

- Project summaries link to their source repositories and avoid unverified performance claims.
- Project cards open case-study summaries covering the question, approach, and verified technologies, with a direct link to each source repository.
- The mobile menu closes with Escape or an outside click.
- Scroll reveals are progressive enhancement, so the content remains visible when animation support is unavailable.
- Open Graph metadata, a canonical URL, and an SVG favicon are included for sharing and browser tabs.
- `assets/Pratham_Gupta_Resume.pdf` is the downloadable, text-based resume.
- Education, selected certificates, contact links, and the profile portrait are based on details supplied by Pratham and the linked LinkedIn profile.
